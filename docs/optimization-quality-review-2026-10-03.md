## 验证方式

- D1 故障覆盖逐章写入前后、日志失败、元数据失败、重启、重复恢复、外部文件编辑和放弃与等待续做的竞争；故障后核对实际正文、revision、元数据及 journal。
- D2 后端使用真实 FastAPI 路由、Orchestrator 和临时存储串联聊天、采纳中断、预览和重启续做；Writer 使用替身，不产生模型费用。
- 前端覆盖恢复组件确认行为、冲突拒绝、卸载后的响应、跨章缓存及 TaskDock 终态；完整 check 包含 lint、typecheck、Vitest 与构建。
- 后端统一 engineering gate 包含 lint、类型合同、完整 pytest、pip check、错误合同、架构边界和依赖同步。复查期间发现的循环依赖已通过调用方显式注入项目根目录消除，没有放宽架构规则。
- 打包使用当前前端和后端源代码、项目内独立 Python 运行时环境，输出到新建诊断目录。对 Electron 包内的真实 sidecar 执行启动、HTTP/WS 认证、SPA 与 CSP smoke，数据目录为临时目录。

## 兼容与验收边界

SQLite journal schema 升至版本 5，补充恢复正文及章节目标元数据；旧 hash-only 行可查看，但材料不足时拒绝续做。放弃只终止剩余写入，已写内容和审计材料保留。多文件写入仍可能部分成功，不承诺跨文件原子性或自动回滚。

新聊天请求可携带 request_id。重复 ID 不重新执行 Writer，也不重放原完整 HTTP 响应，应读取权威会话历史；主 turn 跨进程重启续跑不在本轮范围。旧 append API 保留兼容，当前页面已停止重复持久化聊天事件。

带身份的选区是当前页面合同；旧客户端仅传 selection_text 时维持兼容提示能力，不能声称与新合同有相同的版本保证。工具快照受保留期和空间上限约束，过期明确失败；多资产恢复材料不依赖这种可过期的工具快照。

本轮是工作区本地工程验收，未提交或推送代码，未发布、签名或安装应用。未执行远端 CI、完整人工浏览器创作金路径、真实模型文学质量或性能/成本验收。本地自动化和包内 sidecar smoke 不能替代这些发布条件；完成条件以根规划中的记录为准。
